Visualizing the datacenter before building it

El proceso comenzó con un render 3D fotorrealista del edificio completo. Cada zona quedó definida desde el inicio: sala de servidores con racks alineados, cuarto de vigilancia con pantallas de monitoreo, recepción, cintoteca y parqueo.

The process started with a photorealistic 3D render of the full building. Each zone was defined from the start: server room with aligned racks, surveillance room, reception, tape library and parking.

Hardware acquisition: what we bought and why

Primer corte: así empezó la estructura

First cut: how the structure began

La construcción física arrancó con cartón negro y blanco medido, marcado y doblado a mano según el plano. El criterio de color fue deliberado: negro por dentro para simular el ambiente controlado de un datacenter real, blanco por fuera para el acabado exterior.

Physical construction started with black and white cardboard measured, marked and hand-folded according to the floor plan. The color scheme was deliberate: black inside to simulate the controlled environment of a real datacenter, white outside for the exterior finish.

Ensamblaje: de piezas sueltas a edificio completo

Assembly: from loose pieces to a complete building

Las divisiones internas se pegaron con pistola de silicón caliente, separando las zonas del plano. En esta fase también se instaló la tira LED cyan que ilumina la sala de servidores — el primer momento en que la maqueta cobró vida con luz.

Internal divisions were glued with a hot glue gun, separating the floor plan zones. The cyan LED strip was also installed in this phase to illuminate the server room — the first moment the model came alive with light.

La estructura exterior quedó montada sobre una base de madera con patas con paredes negras y blancas/plateadas. El agujero en la base permite el paso del cableado de la electrónica hacia el interior.

The exterior structure was mounted on a wooden base with legs combining black and white/silver walls. The hole in the base allows electronics wiring to pass through into the interior.

El cerebro del sistema: Arduino Mega 2560

The system brain: Arduino Mega 2560

Antes de conectar ningún cable físico, se diseñó el circuito completo en Proteus. El esquema muestra el Arduino Mega 2560 (ATMEGA2560) como controlador central, conectado al sensor DHT22 de temperatura y humedad, un Touch Sensor y un buzzer de alarma.

Before connecting any physical cable, the full circuit was designed in Proteus. The schematic shows the Arduino Mega 2560 (ATMEGA2560) as the central controller, connected to the DHT22 temperature and humidity sensor, a Touch Sensor and an alarm buzzer.

Simular primero permitió detectar errores de conexión y validar la lógica antes de arriesgar los componentes reales. El DHT22 en simulación ya reportaba 80% de humedad y 27°C, valores que luego confirmamos en el dashboard de Grafana.

Simulating first allowed detecting wiring errors and validating logic before risking real components. The DHT22 in simulation already reported 80% humidity and 27°C, values later confirmed in the Grafana dashboard.

Alimentación: baterías 18650 como fuente autónoma

Power supply: 18650 batteries as autonomous source

Como fuente de energía se usaron baterías recargables 18650 Garberiel de 3.7V en un portabaterías de 3 slots, entregando ~11.1V que se regulan a 5V mediante un módulo regulador ajustable con capacitores de filtro de 220µF y 100µF.

As the power source, Garberiel 18650 3.7V rechargeable batteries in a 3-slot holder were used, delivering ~11.1V regulated to 5V through an adjustable regulator module with 220µF and 100µF filter capacitors.

Este esquema permite que la maqueta funcione completamente autónoma, sin depender de corriente — igual que un sistema real con UPS que mantiene operación ante cortes de energía.

This setup allows the model to operate fully autonomously, without relying on a wall outlet — just like a real system with UPS that maintains operation during power outages.

Grafana Cloud: el datacenter visible en tiempo real

Grafana Cloud: the datacenter visible in real time

Los datos de los sensores se publican en un dashboard de Grafana Cloud en veloxdatacenter.grafana.net. El panel muestra 4 gauges en tiempo real: Alarma (0 = sin incidente), Humedad (60%), Temperatura (24.5°C) y el timestamp del último dato recibido.

Sensor data is published to a Grafana Cloud dashboard at veloxdatacenter.grafana.net. The panel shows 4 real-time gauges: Alarm (0 = no incident), Humidity (60%), Temperature (24.5°C) and the last data timestamp.

La fuente de datos es Amazon DynamoDB, donde el Arduino publica mediciones a través de una función Lambda. La query SELECT * FROM "Mediciones_DataCenter" LIMIT 50 trae los últimos registros para construir las gráficas de tendencia.

The data source is Amazon DynamoDB, where the Arduino publishes measurements through a Lambda function. The query SELECT * FROM "Mediciones_DataCenter" LIMIT 50 fetches the latest records to build trend charts.

Stack: Arduino → DynamoDB → Grafana Cloud Intervalo: 20 minutos Interval: 20 minutes

Sistema RFID: demos en funcionamiento

RFID system: live demos

El módulo RC522 valida cada tarjeta en milisegundos. Si el UID está registrado, el servomotor abre la puerta simulada y el LED verde se activa. Si la tarjeta es desconocida, el LED rojo y el buzzer alertan el intento fallido.

The RC522 module validates each card in milliseconds. If the UID is registered, the servo motor opens the simulated door. If the card is unknown, the red LED and buzzer alert the failed attempt.

Acceso denegado Access denied
Tarjeta no autorizada: alerta roja
Unauthorized card: red alert

Al presentar una tarjeta con UID no registrado, el sistema activa el LED rojo y el buzzer, registrando y rechazando el intento de acceso no autorizado.

When an unregistered UID card is presented, the system activates the red LED and buzzer, logging and rejecting the unauthorized access attempt.

Acceso autorizado Access granted
Tarjeta autorizada: el servo abre la puerta
Authorized card: servo opens the door

Con un UID válido, el Arduino acciona el servomotor que simula la apertura de la sala de servidores. El LED verde confirma el acceso y el servo regresa a posición cerrada automáticamente.

With a valid UID, the Arduino activates the servo motor simulating the server room door opening. The green LED confirms access and the servo returns to closed position automatically.
